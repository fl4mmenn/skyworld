# Skyworld

A modern take on the Classic Skyblock map from `Noobcrew`.

I wanted to have a Skyblock map that varies with seed and leverages modern Minecraft worldgen features.

Celebrate the 15th year of Skyblock and download the original map at `skyblock.net`


# Map description

The overworld consists of :
- a main island
- an end portal
- a floating pointed dripstone

The nether should be one fortress floating in an empty Nether Wastes biome.


## Biomes

The overworld biomes match your seed in minecraft, except for the `skyworld` namespace.

(`minecraft:plains` turns to `skyworld:plains`)
